# LocationSpoofer

Android 定位、路线及环境数据模拟项目的独立 fork。

> 本仓库基于原作者最后公开的 3.0.0 源码维护。原作者仓库已归档。
> 本 fork 不包含账号登录模块，也不依赖原作者账号服务器。3.0.21 是本 fork 的版本号，不表示包含原作者闭源安装包 3.0.20-beta.2 的全部功能。

## 下载与安装

从 [本仓库 Releases](https://github.com/nsuanningmeng/LocationSpoofer-fork/releases) 下载：

- `scoped`：非全局方案，在 LSPosed 中选择目标应用。
- `global`：全局方案，按模块建议配置系统作用域。
- `arm64-v8a`：64 位 ARM 设备；`armeabi-v7a`：32 位 ARM 设备。
- 两个方案使用相同包名，二选一安装。Root 和 LSPosed 的要求保留。

本 fork 使用独立、固定的发布签名，**不能直接覆盖原作者签名的安装包**。迁移前先从旧版导出数据；若旧版因登录不可用而无法导出，请先保留旧版及数据备份，不要直接卸载。只有确认数据已备份后，再停用并卸载旧模块，安装本 fork、启用模块并重启。原作者后期私有版本的数据格式可能不同，不能保证直接兼容。

本 fork 后续版本沿用同一发布签名，可覆盖升级。应用内更新、项目入口和适配文档指向本仓库。地图和可选 WiGLE / OpenCellID 服务仍需各自有效的 API 配置。

## 项目说明

本项目包含定位数据模拟、路线回放、无线环境数据采集及传感器数据模拟等实现，部分功能涉及 Root 权限与 LSPosed／Xposed 系统接口 Hook。

这些能力可用于自有应用或已获得明确授权的测试环境，例如：

- 定位与坐标转换测试。
- 路线回放及应用兼容性验证。
- 无线环境与传感器接口测试。
- Android 系统接口与跨进程通信研究。

模拟数据不代表设备的真实位置、真实运动状态或真实无线环境，不应作为实际到场、运动成绩、考勤或其他真实性证明。
