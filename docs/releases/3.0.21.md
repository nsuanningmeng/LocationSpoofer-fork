## 验证范围

本地 187 项单元测试通过（包含 scoped / global 两种方案）。发布流程检查四个 APK 的签名及固定证书指纹。尚未连接 Android 设备进行真机运行验证，系统兼容性仍以设备实测为准。

## 安装

`scoped` 为非全局方案，`global` 为全局方案，二选一；通常选 `arm64-v8a`，32 位 ARM 设备选 `armeabi-v7a`。Root、LSPosed 和地图服务所需的 API 配置仍需自行准备。

**本 fork 无法直接覆盖原作者或其他构建者签名的安装包，包括使用其他 Debug 证书的 3.0.0。** 请先备份旧版数据；若因旧版登录失败而无法导出，先保留旧版和数据，不要直接卸载。确认有备份后，再停用并卸载旧模块、安装本 fork、启用模块并重启。原作者后期私有版本的数据格式可能不兼容，不能保证导入。

这是公开源码的独立构建，不包含原作者后期未公开的功能和云服务。之后本 fork 内的更新可保留相同签名并覆盖安装。
